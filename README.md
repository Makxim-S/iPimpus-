# 🏠 Family Control Homework Bot

## V0.1 Beta Release

Telegram-бот для семейного контроля учебного времени, домашних заданий и
учебного расписания детей. Бот объединяет Telegram, AI-проверку дневника и
работ, голосовые ответы, расписание и опциональное управление временем через
Google Family Link.

> ⚠️ Это ранняя Beta-версия. Перед использованием на реальных аккаунтах
> обязательно протестируйте все сценарии на небольших лимитах и сохраните
> резервную копию настроек.

## ✨ Возможности V0.1

- 👨‍👩‍👧‍👦 отдельные роли: ребёнок, родитель и администратор;
- 👋 персональные приветствия для детей;
- 🛠️ административная панель с настройками и ручной выдачей времени;
- ⏱️ бонусы за выполнение домашних заданий и экстренная кнопка `+5 минут`;
- 📚 расписание с понедельника по пятницу;
- ✅/❌ статусы предметов: выполнено, не сдано или ещё ожидает проверки;
- 📓 проверка фотографии дневника через AI;
- 📝 проверка домашних заданий по фотографии;
- 🎙️ голосовые сообщения для заданий «прочитать»;
- 💬 режим общения с AI через OpenRouter;
- 🖼️ отправка фотографии вместе с текстовым вопросом в режиме общения;
- 📍 получение геопозиции ребёнка с временем последнего обновления;
- 🎉 автоматический бонус детям в выходные дни;
- 🔐 настройка получателя запросов: родитель, администратор или оба.

## 🧩 Как устроен проект

| Файл | Назначение |
| --- | --- |
| `bot.py` | Telegram-бот, роли, меню, расписание, дневник, ДЗ и бонусы |
| `homework_ai.py` | Проверка дневника/ДЗ, общение и транскрибация голосовых сообщений |
| `config.py` | Конфигурация детей из переменных окружения |
| `familylink_control.py` | Время и геопозиция через Family Link API |
| `schedule_store.py` | Список предметов и расписание |
| `daily_store.py` | Состояние текущего учебного дня и результаты проверок |
| `data/` | Локальные данные и фотографии; не публикуется в Git |
| `.env.example` | Шаблон конфигурации без секретов |

### 🔄 Поток проверки домашнего задания

```text
Ребёнок → фотография дневника → AI определяет предметы и ДЗ
        → расписание получает статусы ✅/❌
        → ребёнок сдаёт работу → AI проверяет результат
        → предмет закрывается → при полном успехе начисляется бонус
```

## 💻 Требования

- Linux-сервер или Linux VM;
- Python 3.11 или новее;
- Telegram-бот;
- ключ OpenRouter;
- ключ Groq для голосовой транскрибации;
- доступ к Family Link и локальный сервис авторизации, если нужны время и
  геопозиция;
- стабильное сетевое соединение.

Windows подходит для редактирования и администрирования, но сам бот следует
запускать в Linux-среде.

## 🚀 Установка с нуля

### 1. Клонирование

```bash
git clone <URL_ВАШЕГО_GITHUB_РЕПОЗИТОРИЯ>
cd family-control-public
```

### 2. Создание виртуального окружения

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Создание конфигурации

```bash
cp .env.example .env
chmod 600 .env
```

Откройте `.env` и заполните значения. Файл `.env` нельзя добавлять в Git.

## 🤖 Создание Telegram-бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Выполните `/newbot`.
3. Задайте имя и username бота.
4. Скопируйте выданный токен в `TELEGRAM_BOT_TOKEN`.
5. Напишите боту `/start`, чтобы Telegram зарегистрировал пользователя.

### Как получить Telegram ID

Для каждого участника откройте [@userinfobot](https://t.me/userinfobot) и
скопируйте числовой ID в соответствующую переменную:

```dotenv
ADMIN_ID=<TELEGRAM_ID_АДМИНИСТРАТОРА>
PARENT_ID=<TELEGRAM_ID_РОДИТЕЛЯ>
CHILD_1_ID=<TELEGRAM_ID_РЕБЁНКА_1>
CHILD_2_ID=<TELEGRAM_ID_РЕБЁНКА_2>
```

Не используйте username вместо числового ID.

## 🧠 Подключение AI

### OpenRouter

1. Создайте аккаунт на [OpenRouter](https://openrouter.ai/).
2. Откройте [страницу ключей](https://openrouter.ai/settings/keys).
3. Создайте API key и сохраните его в `OPENROUTER_API_KEY`.
4. Пополните баланс или выберите доступную модель согласно условиям
   OpenRouter.

OpenRouter используется для проверки дневника, домашних работ и режима
общения. Модель и логика вызовов находятся в `homework_ai.py`.

### Groq

1. Создайте аккаунт на [Groq Console](https://console.groq.com/).
2. Откройте [раздел API Keys](https://console.groq.com/keys).
3. Создайте ключ и запишите его в `GROQ_API_KEY`.

Groq используется для расшифровки голосовых сообщений ребёнка.

`GEMINI_API_KEY` оставлен в шаблоне для совместимости с экспериментальными
сценариями и тестами. Для основной логики V0.1 он не является обязательным.

коммитах. Они должны храниться только в `.env` на сервере.

## 📱 Google Family Link

Интеграция Family Link нужна для добавления времени и получения геопозиции.
Необходимые переменные:

```dotenv
FAMILYLINK_API_KEY=<ключ_локального_сервиса_авторизации>
GOOGLE_API_KEY=<ключ_доступа_к_API>
```

Бот обращается к локальному сервису авторизации по адресу
`http://127.0.0.1:8099`. Этот сервис не входит в публичную копию и должен быть
настроен отдельно на сервере. Без Family Link функции времени и геопозиции
работать не будут, остальные функции могут использоваться отдельно.

### 🔐 Настройка локального auth-сервиса

В публичной копии нет cookies и приватных данных Google. Бот ожидает отдельный
локальный сервис авторизации, который уже имеет законный доступ к собственному
аккаунту владельца и работает только на том же сервере. Это разделение нужно,
чтобы сессионные данные никогда не попадали в GitHub или в код бота.

#### Что должен предоставлять auth-сервис

Сервис должен слушать только loopback-интерфейс и поддерживать:

```text
GET http://127.0.0.1:8099/api/cookies
Header: X-API-Key: <значение FAMILYLINK_API_KEY>
Response: {"cookies": [{"name": "...", "value": "..."}]}
```

Боту необходимы действующие cookies собственного авторизованного аккаунта,
включая необходимые Google-сессионные значения. Бот использует их только в
оперативной памяти для запроса Family Link API и не должен сохранять их в
`data/`, логах или Telegram-сообщениях.

#### Безопасная последовательность настройки

1. Создайте отдельную Linux VM или отдельный сервер, не используйте рабочий
   компьютер как публичный auth-сервис.
2. Установите обновления ОС, включите firewall и запретите внешний доступ к
   порту `8099`.
3. Включите VNC только при необходимости. Разрешите VNC исключительно через
   SSH-туннель или VPN, без проброса порта VNC в интернет.
4. Откройте графическую сессию VM и войдите в собственный Google-аккаунт
   штатным способом. Не используйте чужие аккаунты и не отключайте защиту
   Google.
5. Настройте свой локальный auth-сервис так, чтобы он сам законным способом
   обновлял авторизацию и возвращал боту временные данные через endpoint выше.
6. Создайте отдельный случайный `FAMILYLINK_API_KEY`, сохраните его только в
   `.env` и в защищённой конфигурации auth-сервиса.
7. Ограничьте права пользователя сервиса, установите права `.env` `chmod 600`
   и включите ротацию ключей.

Пример безопасного доступа к VNC через SSH:

```bash
ssh -N -L 5901:127.0.0.1:5901 user@server
```

Затем VNC-клиент подключается к `127.0.0.1:5901`; порт `5901` при этом не
открывается наружу. Конкретные команды запуска VNC зависят от дистрибутива и
выбранного сервера, поэтому их нужно брать из документации установленного
VNC-пакета.

#### Проверка подключения

Не выводите ответ endpoint в терминал, потому что он содержит cookies. Можно
проверить только HTTP-статус:

```bash
curl -sS -o /dev/null -w '%{http_code}\n' \
  -H "X-API-Key: ${FAMILYLINK_API_KEY}" \\
  http://127.0.0.1:8099/api/cookies
```

Ожидаемый статус — `200`. При `401/403` проверьте ключ auth-сервиса, при
`connection refused` — запущен ли сервис и слушает ли он `127.0.0.1:8099`.

#### Что не следует делать

- не извлекайте cookies из браузера через DevTools, снифферы или прокси;
- не публикуйте cookies, `SAPISID`, заголовки авторизации и скриншоты с ними;
- не передавайте сессионные данные через Telegram, Issues или логи;
- не делайте `8099` или VNC доступными из интернета;
- не отключайте MFA, защиту аккаунта и предупреждения Google.

Пошаговая инструкция по извлечению cookies или обходу официального клиента в
open-source README намеренно не публикуется: такие cookies равносильны ключу
от сессии. Для публичного проекта используйте собственную юридически
разрешённую интеграцию и официальную документацию Google.

## 📚 Расписание

Расписание редактируется через интерфейс администратора/родителя и хранится
локально в `data/`:

1. Запустите бота.
2. Откройте аккаунт администратора или родителя.
3. Перейдите в расписание.
4. Выберите ребёнка, день недели и предметы.
5. Проверьте расписание отдельно для каждого настроенного ребёнка.

Текущий день выбирается автоматически. Тестовый выбор дня доступен только в
администраторском аккаунте и предназначен для проверки Beta-сценариев.

## ▶️ Запуск и остановка

```bash
source .venv/bin/activate
python bot.py
```

Остановка в foreground-режиме: `Ctrl+C`.

Для постоянной работы используйте systemd, supervisor или другой менеджер
процессов. Минимальный пример systemd-сервиса:

```ini
[Unit]
Description=Family Control Homework Bot
After=network-online.target

[Service]
WorkingDirectory=/path/to/family-control-public
ExecStart=/path/to/family-control-public/.venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now family-control-homework-bot
sudo systemctl status family-control-homework-bot
journalctl -u family-control-homework-bot -f
```

## 🧪 Проверка перед первым запуском

```bash
source .venv/bin/activate
python -m py_compile bot.py homework_ai.py familylink_control.py \
  config.py daily_store.py schedule_store.py
```

Проверьте `/start`, роли, меню обоих детей, расписание, AI-запрос, голосовое
сообщение, геопозицию и отсутствие `.env` в `git status`.

## 🛠️ Диагностика

```bash
python --version
python -m pip check
systemctl status family-control-homework-bot
journalctl -u family-control-homework-bot -n 100 --no-pager
```

Ошибка Telegram `Conflict` обычно означает, что один токен используется двумя
процессами. Если AI не отвечает, проверьте `OPENROUTER_API_KEY`, лимиты и сеть.
Для голоса отдельно проверьте `GROQ_API_KEY`. Для Family Link проверьте оба
ключа, ID детей/устройств и сервис на `127.0.0.1:8099`.
